## ZombieFarm v3.3.0 · 방어 진형과 작은 칸

- **방어 진형 10종**: 벽을 한 칸씩 사서 세우는 대신, 모양을 고르고 값을 한 번 내면 집 둘레에 벽 전체가 섭니다. 한 번 산 진형은 언제든 값 없이 다시 고를 수 있습니다.

  | 진형 | 값 | 특징 |
  | --- | --- | --- |
  | 한 겹 울타리 | 기본 | 닫힌 한 겹 |
  | 미로 입구 | 6,000 | 북쪽 입구 + 안쪽 가로벽 |
  | 이중 벽 | 12,000 | 닫힌 두 겹 |
  | 이중 미로 | 18,000 | 두 겹, 입구가 남북으로 엇갈림 |
  | 망루 성벽 | 24,000 | 닫힌 벽 + 모퉁이 타워 4곳 |
  | 깔때기 킬존 | 28,000 | 남쪽 입구 앞의 긴 목 + 타워 2곳 |
  | 삼중 벽 | 32,000 | 닫힌 세 겹 |
  | 나선 요새 | 36,000 | 집을 한 바퀴 돌아야 들어옴 |
  | 삼중 미로 | 45,000 | 세 겹, 입구가 남 · 북 · 남 |
  | 별 요새 | 65,000 | 삼중 미로 + 타워 6곳 |

- **타워가 딸린 진형**: 진형의 타워는 옆에서 행동 버튼으로 강화하고, 강화한 단계는 진형을 바꿔도 자리마다 이어집니다.
- **직접 설계**는 마지막 메뉴로 남겼습니다. 벽 · 타워 · 덫을 놓는 칸만큼 그 자리에서 값을 내고, 거두면 절반을 돌려받습니다. 상점에서 벽을 묶음으로 사는 메뉴는 없앴습니다.
- **칸 크기 절반**: 땅의 칸이 60에서 30으로 줄어 벽 모양을 더 촘촘하게 그릴 수 있습니다. 벽 한 칸의 값도 절반입니다(나무 80 · 벽돌 450 · 철 1,500원).
- **둥근 구덩이**: 삽질 한 번에 작은 칸 12개가 둥글게 파입니다. 같은 자리를 다시 파면 전체가 한 단계씩 깊어지고, 다섯 번째에 지하수가 솟습니다. 메울 때도 둥근 자리 전체가 메워집니다.
- 벽은 이어진 줄마다 하나로 묶어 그려, 칸이 수백 개여도 가볍습니다.
- 이전 저장: 직접 세운 벽 한 칸은 작은 칸 넷으로, 구덩이도 넷으로 옮겨집니다. 집 울타리는 같은 종류의 새 진형으로 다시 섭니다.
