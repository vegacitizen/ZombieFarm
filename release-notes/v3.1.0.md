## ZombieFarm v3.1.0 · 집 울타리와 밤 예보

- **기본 집 울타리**: 집 둘레에 처음부터 나무 울타리가 둘러져 있습니다. 밤에 부서진 칸은 아침마다 다시 섭니다. 이전 저장을 불러와도 세워 줍니다.
- **소재 강화**: 나무 → 벽돌(15,000원) → 강철(50,000원). 값이 비싼 대신 모든 칸이 한꺼번에 바뀝니다.
- **형태 강화**: 둥근 울타리 → 미로 입구(6,000원) → 이중 미로(18,000원) → 나선 요새(35,000원). 좀비가 문까지 걷는 길이 길어집니다. 벽이 단단할수록 미로가 잘 통합니다.
- **오늘 밤 예보**: 낮 동안 화면 아래에 오늘 밤 좀비의 수 · 웨이브 · 방어 등급이 뜨고, 누르면 보강하면 좋은 것을 알려 줍니다. 아침 결과 화면에도 요약이 나옵니다.
- 방어 설계 화면의 벽돌 벽과 철벽 값을 올렸습니다.
